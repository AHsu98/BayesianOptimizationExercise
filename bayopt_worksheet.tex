\begin{enumerate}
    \item Assume that 
    \[
        f \sim GP\left(\mu(x), k(x,x')\right)
    \]
    and that 
    \[
        y_{i} \mid f(x_i) \sim N\left(f(x_{i}), \sigma^{2}\right)
    \]
    What is the distribution of $f\mid y_{i}$? This is well defined even if $\sigma^{2}=0$.

    Hint1: This will be another Gaussian process, and is thus characterized by the conditional mean
    \begin{equation*}
        \mathbb{E}\left[f(x) \mid y_{i}\right]
    \end{equation*}
    and the conditional covariance
    \begin{equation*}
        \mathbb{E}\left[f(x)f(x') \mid y_{i}\right] - \mathbb{E}\left[f(x) \mid y_{i}\right]\mathbb{E}\left[f(x') \mid y_{i}\right]
    \end{equation*}

    Hint2: You may want to consider the joint (unconditional distribution) of $(y_i,f(x))$ and $(y_i,f(x),f(x'))$.



    \vspace{3cm}

    \item How can you represent this in code using the kernel function? 
    If we're doing Bayesian optimization, we may be evaluating the posterior mean 
    and posterior covariance many times for each update. 

    \vspace{3cm}

    \item How does this change if we condition on multiple observations? Suppose that 
    we've already conditioned on a set of $n$ observations $\left\{(x_{i},y_{i})\right\}_{i=1}^{n}$. 
    How can we condition on one more?

    \vspace{3cm}

    \item What are the gradients of the posterior mean and variance with respect to $x$? 
    That is, we assume that 
    \[
        f_{post} \sim GP\left(\mu_{post}(x), k_{post}(x,y)\right)
    \]
    In terms of the representation that you found in 2., what is $\nabla_{x}\mu_{post}(x)$,
    and $\nabla_{x}k_{post}(x,x)$?

\end{enumerate}

\textbf{Setup for a PDE inverse problem:} Suppose that $u(x,t)$ satisfies the PDE
\begin{align}
    u_t &= \alpha u u_{x} + \kappa u_{xx} \\
    u(x,0)&= a \sin(6\pi x) - b \cos(2\pi x) -1\\
    u(0,t) &= u(1,t)\\
\end{align}
with for some parameters $(\alpha,\log(\kappa),a,b)$. 

We observe points $\{(x_i,t_i,u_i)\}_{i=1}^n$ where $u_i = u(x_i,t_i)$. 
Your goal is to recover the parameters $p = (\alpha,\log(\kappa),a,b)$ from data, 
where we assume that 
\begin{align}
    \alpha &\in (0,1) \\
    \log(\kappa) &\in (-6,0) \\
    a &\in (-5,5) \\
    b &\in (-5,5) \\
\end{align}

We've provided code that solves the PDE above for any set of parameters $p$, giving 
us a solution $u_p(x,t)$ for any $p$ (but evaluating for any value of $p$ requires a PDE solve). 

Try to recover the true parameters $p^*$ by finding parameters $\hat{p}$ to minimize 
\begin{equation}
    L(p) = \frac{1}{2}\sum_{i=1}^n (u(x_i,t_i) - u_i)^2
\end{equation}
using Bayesian optimization. 

We've provided code for both this solution map $p\to u_p$, and which evaluates the loss 
$L(p)$.
